# Evaluación Parcial 1 - Machine Learning

Repositorio correspondiente a la Evaluación Parcial 1 de MLY0100 Machine Learning.

## Archivos

- `Evaluación Parcial 1 - Enunciado.pdf`: enunciado de la evaluación.
- `Evaluación Parcial 1 - Guía Estudiante.pdf`: guía y pauta de revisión.
- `notebook/evaluacion_parcial_1.ipynb`: desarrollo de las fases 1, 2 y 3 de CRISP-DM.

## Dataset

El notebook utiliza el archivo:

`Evaluación Parcial 1 - Dataset.zip`

Antes de ejecutar el notebook, el ZIP debe estar en una de estas ubicaciones:

- raíz del proyecto;
- carpeta superior al notebook;
- `/content` si se utiliza Google Colab.

El código busca automáticamente el ZIP y extrae `DS1-18-Datos-Properati.csv` directamente desde él.

## Ejecución

1. Abrir `notebook/evaluacion_parcial_1.ipynb` en Jupyter Notebook o Google Colab.
2. Tener disponible el ZIP del dataset.
3. Ejecutar todas las celdas en orden desde el inicio.
4. Al final se genera `DS1-18-Datos-Properati-preparado.csv`.

El CSV preparado es un archivo generado por el notebook y no es necesario almacenarlo en el repositorio para ejecutar el análisis.
